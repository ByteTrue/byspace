# Infrastructure Automation

Use when the user asks for IaC, environment setup, platform config, or repeatable provisioning.

## Workflow

1. Capture target environment, resources, network, identity, runtime, and compliance needs.
2. Identify existing IaC/config conventions.
3. Propose resource structure, state handling, variables, secrets, and ownership.
4. Define plan/apply validation, drift detection, rollback, and approval gates.
5. Document operational handoff and remaining risks.

## Output

Return an infrastructure automation plan with resource map, IaC shape, permissions, validation, rollback, and handoff.
