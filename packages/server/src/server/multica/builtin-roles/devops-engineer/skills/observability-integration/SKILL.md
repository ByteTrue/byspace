# Observability Integration

Use when a service, release, or platform needs monitoring, dashboards, logs, traces, or health checks.

## Workflow

1. Identify service, critical user journeys, dependencies, and failure modes.
2. Define golden signals, logs, traces, dashboards, and alert thresholds.
3. Connect observability to release verification and rollback criteria.
4. Add ownership, escalation path, and runbook links.
5. Document gaps and next instrumentation tasks.

## Output

Return observability plan with metrics, logs, traces, dashboards, alerts, owners, and release checks.
