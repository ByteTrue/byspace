# Task Breakdown

Use when a goal, PRD, issue list, or project brief needs to become executable work.

## Workflow

1. Identify scope, deliverables, constraints, and target milestone.
2. Split work into independently trackable tasks.
3. Add owner, dependency, estimate, priority, and acceptance criteria for each task.
4. Mark ambiguous requirements and decision blockers.
5. Recommend sequencing and the next checkpoint.

## Output

Return a task table with owner, dependency, estimate, acceptance criteria, risk, and sequence.
