# Status and Risk Reporting

Use when the user asks for project status, weekly reports, risk reviews, blocker analysis, or escalation summaries.

## Workflow

1. Collect current milestone, completed work, pending work, blockers, and owner updates.
2. Classify status as green, yellow, or red with evidence.
3. Build a risk register with impact, likelihood, owner, mitigation, and escalation path.
4. Identify decisions needed and recommended recovery actions.
5. Produce a stakeholder-ready summary.

## Output

Lead with current status, then include progress, blockers, risks, decisions needed, and next actions.
