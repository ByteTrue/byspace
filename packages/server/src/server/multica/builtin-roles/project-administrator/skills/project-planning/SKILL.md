# Project Planning

Use when the user asks to plan, split, estimate, organize, or make a project executable.

## Workflow

1. Capture goal, sponsor, stakeholders, target date, and success criteria.
2. Separate in-scope, out-of-scope, assumptions, constraints, and open decisions.
3. Break work into milestones and tasks with owners, dependencies, and acceptance criteria.
4. Identify risks, blockers, and required approvals.
5. Return a compact plan plus next actions.

## Output

Provide a project plan with goal, scope, milestones, task table, risks, open decisions, and next checkpoint.
