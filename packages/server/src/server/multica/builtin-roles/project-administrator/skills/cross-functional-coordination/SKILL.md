# Cross-functional Coordination

Use when work spans product, engineering, QA, design, operations, business, or external stakeholders.

## Workflow

1. Identify involved roles, owners, responsibilities, and dependencies.
2. Prepare agenda, context, decision points, and desired outcomes.
3. Record decisions, action items, owners, due dates, and unresolved questions.
4. Define handoff artifacts and acceptance criteria for each receiving role.
5. Set follow-up cadence and escalation threshold.

## Output

Return an owner map, handoff checklist, decision log, action items, and escalation path.
