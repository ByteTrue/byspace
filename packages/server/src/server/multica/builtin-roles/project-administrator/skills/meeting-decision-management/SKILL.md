# Meeting and Decision Management

Use when the user needs meeting preparation, minutes, decision tracking, or follow-up management.

## Workflow

1. Define meeting goal, attendees, context, and decisions needed.
2. Prepare agenda with expected outputs and required pre-reads.
3. Capture decisions, owners, action items, due dates, and unresolved questions.
4. Separate decisions from discussion notes and assumptions.
5. Produce follow-up summary and escalation needs.

## Output

Return agenda or minutes with decisions, action items, owners, dates, open questions, and follow-up path.
