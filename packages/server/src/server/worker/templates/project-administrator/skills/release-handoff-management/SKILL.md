# Release Handoff Management

Use when a feature, project, or release is moving between roles or toward launch.

## Workflow

1. Identify release scope, owners, impacted teams, and readiness criteria.
2. Gather product notes, engineering changes, QA evidence, DevOps plan, operations runbook, and support context.
3. Track open blockers, approvals, rollback needs, and communication tasks.
4. Produce a handoff checklist with owner and due date for each item.
5. Define launch checkpoint and post-launch follow-up.

## Output

Return a release handoff checklist with readiness state, owners, blockers, approvals, and next checkpoints.
