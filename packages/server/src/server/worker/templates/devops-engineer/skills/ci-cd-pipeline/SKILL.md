# CI/CD Pipeline

Use when the user asks to create, review, or improve a delivery pipeline.

## Workflow

1. Identify repository, runtime, package manager, environments, and deployment target.
2. Inspect existing build, test, scan, artifact, and deployment steps.
3. Design pipeline stages with inputs, outputs, caches, artifacts, and permissions.
4. Add security, secret handling, approval, rollback, and health-check gates.
5. Provide validation commands and residual risk.

## Output

Return a pipeline design or patch plan with stages, triggers, secrets, artifacts, validation, and rollback.
