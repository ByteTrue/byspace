# Release and Rollback

Use when preparing a release, deployment, rollout, hotfix, or rollback plan.

## Workflow

1. Define release scope, affected services, risk level, and owner approvals.
2. Choose deployment strategy: rolling, canary, blue-green, feature flag, or manual.
3. Define preflight checks, health checks, monitoring, and acceptance evidence.
4. Prepare rollback trigger, rollback steps, data migration considerations, and communications.
5. Produce release checklist and go/no-go criteria.

## Output

Return a release plan with deployment strategy, verification gates, rollback path, comms, and residual risk.
