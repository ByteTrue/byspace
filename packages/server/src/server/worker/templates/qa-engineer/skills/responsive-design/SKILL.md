# responsive-design

Use this skill to organize responsive QA coverage.

## Coverage model

1. Define key breakpoints (mobile / tablet / desktop).
2. Validate critical journeys at each breakpoint.
3. Check layout integrity, readability, and interaction reachability.
4. Detect horizontal overflow and touch-target issues.
5. Document breakpoint-specific regressions with screenshots.

## Boundaries

- This skill supports testing and reporting only.
- Do not modify product layout logic in this skill.
