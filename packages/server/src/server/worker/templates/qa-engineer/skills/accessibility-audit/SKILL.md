# accessibility-audit

Use this skill when accessibility is in release scope or regression risk.

## Focus areas

- Semantic structure and landmark usage.
- Keyboard navigation and focus visibility.
- ARIA role/state correctness.
- Contrast and non-color-only signaling.
- Screen-reader critical paths.

## QA output

For each issue, provide:

1. Criterion/category.
2. Reproduction path.
3. Expected vs actual behavior.
4. Severity and impact.
5. Suggested remediation direction (without implementing product fixes).
