# BySpace

BySpace lets you monitor and control local AI coding agents from mobile, web, desktop, and the command line. This baseline is derived from [Paseo](https://github.com/getpaseo/paseo).

## Install the beta

```bash
npm install -g @bytetrue/byspace@beta
byspace
```

The production daemon defaults to `127.0.0.1:6777` and stores state under `~/.byspace`. Override them with `BYSPACE_LISTEN` and `BYSPACE_HOME`.
