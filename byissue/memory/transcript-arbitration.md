# 会话归档仲裁与工具回显陷阱

## 结论

- 判断 agent 到底做了什么，用会话归档仲裁，不信模型记忆：pi 会话 JSONL 在 `~/.pi/agent/sessions/<cwd-dir>/<ts>_<id>.jsonl`。
- `rg -rn` 在所有平台都被解析为 `-r n`（--replace n），输出看起来像压缩过的回显污染；曾据此误判 483 次工具调用，实际只有 1 次真异常。搜索时 flags 分开写。
- 工具回显异常先分清三个来源：搜索 flag 误用、模型转述失真、真实异常；归档是唯一仲裁者。

## 依据

- 类型：可重跑证明（483 次调用的仲裁实际做过）。
- 被否决的相关方案：信模型对历史的转述；把 rg 输出异常直接当工具故障。
- 证据或复核方式：笔记 `byissue/archive/v1/notes/003-tool-echo-pollution-three-culprits.md`。
- 适用条件：排查 agent 行为争议、审计工具调用历史。JSONL 路径是 pi 的存储约定，pi 版本变化需复核。

## 重访条件

- pi 会话存储路径/格式变更。
