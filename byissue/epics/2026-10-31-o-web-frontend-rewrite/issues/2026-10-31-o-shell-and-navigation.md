# 外壳和导航：根布局、全部页面地址、侧栏、快捷键、命令面板、主题、多语言

## 目标与范围

把旧版根布局（`packages/app/src/app/_layout.tsx`）和侧栏的功能在 `web/` 里做全，页面内容以外的部分都按旧版对齐。对照基线是旧版 8081 的实际行为，逐项比对，不以「能用了」为准。

包含：

1. **根布局**：旧版根布局挂的每一样都要有对应：查询缓存、多语言、错误边界、快捷键分发、提示条、启动等待（5 秒放弃等待和重试）、推送通知点击跳转、侧栏提示卡片、外观（主题和字号）、配对链接（`#offer=`，导入主机后跳到 `/open-project`）、每个主机一份会话（含旧收藏迁移）、标签页图标状态、切到后台时保存草稿。
2. **页面地址**：旧版 22 个路由文件一一对应，启动跳转（`/` → 主机 → 记住的工作区或 `/open-project`）、未知主机重定向、agent 链接解析都用共享逻辑。内容在后面几步做的页面显示明确的「这一页在第 N 步迁移」，不出现空白页。
3. **外壳规则**：哪些页面隐藏侧栏（`/`、`/welcome`、`/pair-scan`、设置页、未知主机），左包右大卡片何时生效，侧栏开关（⌘B）、宽度、专注模式，窄屏下侧栏改为抽屉。
4. **侧栏**：和旧版 `LeftSidebar` 功能对齐，动手前先逐个组件列清单写进执行记录。
5. **快捷键**：共享的 `useKeyboardShortcuts`、工作区快捷键（⌘1–9 等）、固定工作区快捷键、快捷键说明弹窗。
6. **命令面板**：⌘K，用 shadcn 的 Command，命令来源沿用共享的注册逻辑。
7. **主题**：8 个主题选项（浅色、深色、跟随系统和 5 个深色变体）以及界面、正文、代码字号设置都生效。
8. **多语言**：`web/` 里的界面文字全部走 `t()`，沿用旧版的文案键。

旧版根布局里属于其他步骤的全局弹窗（服务商设置、添加项目流程、诊断、更新日志等），在执行记录里逐个写明归到哪一步。

## 验证

- 每个改到的界面都和旧版 8081 并排截图对照，浅色深色各一张。
- 侧栏、启动跳转、快捷键、命令面板逐项手动操作一遍，结果写进执行记录。
- 侧栏行等关键元素带上旧版的 `data-testid`。
- `npm run typecheck`、`npm run lint`、`npm run format:check` 通过。
