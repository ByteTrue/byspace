# 其余页面：设置、主机和配对、项目、历史、定时任务、隧道、欢迎页、全局弹窗

## 目标与范围

新前端里剩下的占位页面和占位弹窗全部换成旧版的实现，对照基线是旧版 8081 的实际行为。从这些路由和弹窗能走到的依赖 React Native 界面的文件约 66 个、2.2 万行。分批做，每批一个提交：

1. **设置框架和应用设置**：设置页本身（左侧分区列表、主机选择、右侧内容卡片，手机上是列表加详情）、通用、外观、通知、关于（版本、更新说明、诊断、已连接主机、社区链接），以及关于页打开的更新说明和诊断弹窗。桌面客户端（Wails）里额外显示的版本更新、命令行工具、配置目录这些行一起做。
2. **主机设置**：主机（外观、网络、后台服务、默认 shell、配对设备、移除主机）、连接（连接列表、添加主机的几种方式、粘贴配对链接）、Agent（提供方列表、提供方设置面板、终端配置、标题生成、技能）、用量。提供方设置面板同时是输入框模型选择里齿轮按钮打开的那个，第 3 步漏了，这批一起挂上。
3. **项目**：项目列表、项目设置、编辑项目、工作区标签，以及侧栏「Add project」打开的添加项目流程。
4. **历史、打开项目、欢迎页、扫码配对、导入会话**。
5. **定时任务、隧道**。

动手前先读旧版对应文件；界面用 shadcn 组件重写，逻辑用共享代码，大文件用 `web/scripts/port/` 的脚本从旧版生成；共享模块里引到 React Native 界面的，在 `web/src/overrides/` 覆盖，对外接口不变。做完后新前端里不再有 `PendingPage`、`PlaceholderPage`、`PendingDialog`。

## 验证

- 每批和旧版 8081 并排截图对照，浅色深色、桌面手机，挑出来的放 `screenshots/web-step4/`，全部对照截图放 `screenshots/对照全集/`。
- 每批涉及的操作在浏览器里逐项做一遍（改设置后刷新还在、增删改真的生效），结果写进执行记录。
- 用前端重写的操作脚本收集客户端「Message validation failed」告警，新出现的 daemon 问题记下并修。
- 关键元素带上旧版的 `data-testid`。
- `npm run typecheck`、`npm run lint`、`npm run format:check` 通过。

## 执行记录

### 第 1 批：设置框架和应用设置（2026-11-01）

**做了什么**

- 设置页本身（`/settings`、`/settings/:section`，以及主机分区和项目两个路由的入口）换成旧版 `settings-screen` 的移植：左侧分区列表、主机选择、内容卡片，手机上是列表加详情。通用、外观（主题、终端主题、时间线详细程度、对话大纲、侧栏导航项的显示和排序、界面和代码字体、字号、预览）、通知（本浏览器的推送开关）、关于（版本、更新说明、诊断、已连接主机、社区链接）都是旧版逻辑。桌面客户端才有的行（版本更新、命令行工具、配置目录）也移植了，只在 Wails 里显示。
- 「更新说明」和「诊断」两个弹窗接上真实实现，原来的两个 `PendingDialog` 删掉了；主机分区和项目页仍是第 2、3 批的占位。
- 生成脚本：`web/scripts/port/` 新增 `_port.py`（各脚本共用的替换工具）、`settings-screen.py`、`appearance-section.py`、`sidebar-nav-section.py`、`desktop-app-section.py`、`changelog-sheet.py`、`app-diagnostic-sheet.py`。
- `web/vite.config.ts`：`packages/app` 里的文件用相对路径引用一个有覆盖版本的模块时，也拿到覆盖版本（原来只有 `@/` 引用会走覆盖，`changelog/index.ts → ./changelog-host` 会直接加载 Expo 文件）；`packages/app/public`（推送用的 service worker、manifest、图标、安装脚本）在开发服务和打包里都放到站点根目录，切换时再搬进 `web/public`。`web/index.html` 加了旧版的 favicon，不再请求不存在的 `/favicon.ico`。

**怎么验证的**

和旧版 8081 并排（同一个开发版 daemon，同视口同操作），截图在 `screenshots/对照全集/步骤4-第1批-设置/`，挑出来的在 `screenshots/web-step4/`：

- 布局：通用、外观、通知、关于四页逐个文字元素比位置、字号、字重、颜色（桌面浅色深色、1440×3200 全长、手机），除下面列的有意差异外为 0 处差异；打开更新说明、诊断后对弹窗内的文字同样比过。
- 操作：改「默认发送」、终端回滚行数、外观第一个开关后刷新，值都还在，再改回原值（`_脚本/probe-settings-persist.js`）；主题菜单、默认发送菜单、侧栏导航项上下移动和开关、更新说明、诊断的复制和刷新。⌘, 打开设置，菜单开着时 Esc 只关菜单，没有弹层时 Esc 回到上次的工作区；agent 运行中用 Esc 关菜单不会打断它，没有弹层时 Esc 才打断（`_脚本/probe-settings-escape.js`、`probe-escape-interrupt.js`），两边结果一致。
- 推送：两个前端都能在本浏览器打开推送（注册 `/push/<serverId>/` 的 service worker）再关掉；真正收到推送需要推送服务，没测。
- 按钮颜色：工作区页、设置各页、新建工作区页，每个带 `data-testid` 或 `aria-label` 的按钮，静止和悬停时的底色和图标颜色逐个和旧版比（`_脚本/probe-hover-colors.js`），浅色深色都为 0 处差异。
- 全部旧的操作脚本（第 2、3 步的 40 多个）对 8082 重跑一遍，没有新的失败和控制台错误。PR 评审折叠、安装脚本工作区两个步骤在旧版上同样超时，是测试数据变了（侧栏多了导航行，测试工作区挪到了视口外），不是回归。

**这一批顺带改的共用部分**（都是为了和旧版一致，影响所有页面）

- 遮罩：对话框、命令面板、侧边抽屉改成旧版的纯黑 50%（shadcn 原来是 10% 加模糊）；手机底部面板改成 45%，工具调用详情 50%。
- 底部面板：拖动手柄改成旧版的 30×4 深灰（菜单面板 36×4 浅灰），上下间距同旧版；菜单面板的上下留白、标题间距同旧版；手机的标签切换改用共用的 Combobox 面板（原来是单独写的抽屉），面板里的行不再有灰底高亮，位置和旧版一致。
- 菜单：子菜单箭头 14px、和右侧取值之间 6px；浮出的子菜单只取最小宽度；勾选图标固定 16px。
- 颜色：新增 `extra-muted-foreground`（旧版 `foregroundExtraMuted`，比 muted 再淡一档），旧版用这个颜色的 14 处（新建标签和分屏按钮、下拉箭头、任务完成的圆圈、提问表单的单选框、滚动条、对话大纲的刻度等）改用它；新增 `interaction-highlight`（旧版图标按钮和 ghost 按钮悬停时的半透明底），图标按钮、工具栏文字按钮、ghost 按钮、侧栏开关悬停时用它，图标颜色悬停不变；侧栏底部的设置、帮助、主机、导入按钮悬停只加深图标、不加底色（旧版就是这样）。
- 其他：按钮里图标和文字的间距统一 6px；侧栏和文件树的拖动调宽条悬停 100ms 后显示 1px 细线；工作区行的状态小圆点改成旧版的 8px 带 1px 描边；需要处理的感叹号图标挖空色、项目字母头像的字号同旧版；侧栏提示卡片的按钮去掉悬停变色；诊断弹窗里长行在卡片内边距处截断；界面和等宽字体的回退顺序和旧版 `theme.ts` 一致；外观页预览的代码行高同旧版；复制到剪贴板失败时（无权限、非安全来源）退回 `execCommand`。

**有意和旧版不同**

- 右对齐的下拉菜单（如语言、主题）右边缘和按钮对齐；旧版会多出 2px（它量菜单宽度时没算边框）。
- 下拉框阴影用 shadcn 的两层 `shadow-md`；旧版只有一层，肉眼几乎看不出。

**没验到的**

- 桌面客户端那几行只在模拟桌面环境（`MOCK_DESKTOP`）下比过布局，没有在真的 Wails 里点过。
- 推送真正投递到浏览器。
