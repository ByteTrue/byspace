# 切换：端到端用例对新前端跑通，构建切到 web/，删除 packages/app 和 Expo

## 目标与范围

新前端在浏览器、桌面窗口、Android 客户端和 PWA 里都已和旧版对等（第 1–5 步）。这一步让它成为唯一的前端。分批做：

1. **端到端用例对 `web/` 跑通**：CI 加一组对 `web/dist` 跑的 Playwright 分片，和旧版那组并行；切换前它只作参考，不挡 CI。失败逐个处理：新前端的缺陷修新前端，有意改过的布局或交互（侧栏导航行等，见各批记录的「有意和旧版不同」）改用例。不适用的用例逐个写明原因。
2. **打包体积**：Mermaid 的运行时（3.5 MB，内联整个 Mermaid）改为第一次画图时再加载。只做这一处：剩下最大的是协议的生成校验器（2.8 MB），启动就要用，拆不出去。
3. **构建切到 `web/`**：`scripts/build-daemon-web-ui.mjs` 和 `make build-web` 改为构建 `web/`；`npm run dev` / `dev:app` 起新前端；CI 端到端只对 `web/` 跑；Docker、发版流程、开发文档同步。切完后正式版下次发版就是新前端。
4. **删除 `packages/app` 和 Expo**：先给用户一份删除清单、把删除前的提交推一个远端存档标签，用户确认后再删。`web/` 还在用的非界面模块（状态、daemon 通信、多语言等）搬进 `web/src`，端到端用例搬到 `web/`，删掉 React Native 界面代码、Expo 和 React Native 依赖、只为 React Native Web 存在的文档（`docs/unistyles.md`、`docs/react-compiler.md`、`docs/expo-router.md` 等）；`AGENTS.md`、`docs/development.md`、`docs/architecture.md` 同步。

用户逐页验收穿插在第 1–3 批之间：每批做完给预览地址。

## 验证

- CI 上对 `web/dist` 的 16 个分片全部通过，不适用的用例在执行记录里逐个列出原因。
- 切换后 `make build-full` 产出的二进制、开发版桌面窗口、Android 安装包都是新前端，各打开一次确认。
- `npm run typecheck`、`npm run lint`、`npm run format:check` 通过；动到 Go 时 `npm run audit` 通过。

## 执行记录

### 批 1：端到端用例对 `web/` 跑通（2026-11-03）

CI 加了 `playwright-web`：同一套 16 个分片，`E2E_STATIC_WEB_DIR` 指向 `web/dist`，`continue-on-error`，不挡 CI；`web/**` 的改动也触发浏览器检查。第一次跑新版 16 片有 15 片失败、约 170 条用例失败，旧版全过。本地按文件对新旧两版各跑一遍，失败分三类处理，最后 run 41488948948 新旧各 16 片全部通过。没有用例被判为不适用、也没有跳过。

**新前端的缺陷，改 `web/`**（逐条和旧版行为对齐）：

- 打开 Settings、History、定时任务时工作区保持挂载（`web/src/app/workspace-layer.tsx`），和旧版导航栈一样：终端、滚动位置、草稿都还在，返回不重建。配套一个 `useIsFocused` 替身，被遮住的工作区不再跳转盖住它的页面；路由去掉 transition，刚打开工作区就按快捷键时作用在新工作区上。
- 对话框关闭后焦点回到打开它的元素；sheet 可见的标题就是对话框标题，屏幕阅读器不再读两遍；桌面 sheet 关闭时 160ms 淡出再报 dismiss，保存配置档后立即再打开编辑不再失败。
- 菜单：去掉退出动画和滑入；`transition-none`，缩放不再从中心漂到角上；右键菜单在指针下方 4px、左边对齐指针；在菜单里点右键不再打开外层的右键菜单。
- 图片查看器里按 Escape 只关查看器，不再同时中断后面的 agent（Mermaid 全屏同理）。
- 侧栏收起后不在 Tab 顺序和无障碍树里；行的 ⋯ 不悬停时隐藏；工作区悬停卡片是以脚本列表命名的 menu。
- 下拉框在上层弹出对话框抢走焦点时不关闭；输入框的补全浮层按底边定位、绘制前测量、在手机侧栏之下；模型列表虚拟滚动（`@tanstack/react-virtual`，几百个模型只挂可见行）。
- 主题色改用 sRGB hex（和旧版 `theme.ts` 换算结果一致），界面字号逐档取整；主机徽标颜色落在图标笔画上。
- 其余：标签页悬停提示、Diff 文件头和目录行长按选中、拆分按钮 28px、⌘K 文件搜索出错文案、添加项目流程输入框聚焦、工作区被遮住时打开的标签返回后显示。

**DOM 有意不同，改用例**：每处在用例或 helper 里标 `COMPAT(web-switch)`，删 `packages/app` 时只留 `web/` 分支（`rg "COMPAT\(web-switch"`）。确认对话框从 `window.confirm` 变成页内 AlertDialog（`helpers/confirm-dialog.ts`）；⌘K 的行是 option；菜单外点击（`web/` 没有遮罩元素，`helpers/menu-backdrop.ts`）；bottom sheet 的遮罩和把手选择器；侧栏工作区行是 link；工具调用 shimmer 用 class 不用行内 style；历史加载转圈是 SVG；弹窗打开时输入框的停止按钮在无障碍树外；侧栏导航行（第 2 步有意去掉了「BySpace ⌄」菜单）。

**daemon 缺陷，改 Go**（`cf11b07ba`）：删除 provider 从来没写进 `config.json`（provider 存在 `agents.providers`，删除只改了平铺的那份），下次读配置或重启就回来了；provider 目录重建一秒多，配置改动期间先开始的构建后完成会覆盖新结果并广播，刚加的 provider 半秒后从列表消失。构建按开始顺序编号，被更新的构建或配置改动超过的结果丢弃，和 Node 的 snapshot manager 丢弃旧 generation 一致。

**本机验不了的**：本机没有 `claude` CLI，导入 Claude 会话那一步只能在 CI 验；`archive-tab` 用的是 OpenCode，本机用 mock agent 的副本验了三条用例都过。

### 批 2：打包体积（2026-11-03）

Mermaid 运行时（3.5 MB，整个 Mermaid 内联在 iframe 的 srcDoc 里）改为第一次画图时加载。首屏 JS 由 12.9 MB（gzip 3.3 MB）降到 9.4 MB（gzip 2.3 MB）。剩下最大的是协议的生成校验器（2.8 MB），启动就要用，不拆。
