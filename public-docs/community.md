# Related projects

These projects are related to BySpace and built by the community.

## Tools and integrations

| Project                                                                                          | What it does                                                                                                                         |
| ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| [BySpace for VS Code](https://marketplace.visualstudio.com/items?itemName=hinnes.byspace-vscode) | Opens the matching BySpace project or worktree in VS Code and adds agent chat, file mentions, and editor links.                      |
| [VS Code Web plugin](https://github.com/itsjustanks/byspace-plugin-vscode-web)                   | Opens a live BySpace worktree in `vscode.dev` through a VS Code tunnel, including workspaces on headless hosts.                      |
| [BySpace Icon](https://github.com/gpambrozio/byspace-menubar)                                    | Shows workspace status across BySpace hosts in the macOS menu bar and opens a workspace with one click.                              |
| [BySpace Cross-Daemon Comms](https://github.com/xpufx/byspace-cross-daemon-comms)                | Lets agents communicate with agents on another BySpace daemon through an MCP server.                                                 |
| [BySpace Antigravity ACP](https://github.com/tiezbro/byspace-agy-acp)                            | Connects Google Antigravity CLI to BySpace through ACP, with BySpace-specific context, permissions, and concurrency handling.        |
| [Desvio](https://github.com/cleiter/desvio)                                                      | Rebuilds a personal fork from a set of branches, using an agent to resolve new conflicts and Git rerere to replay known resolutions. |

## Hosting and infrastructure

| Project                                                                | What it does                                                                                           |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| [BySpace Self-hosted](https://github.com/blockfeed/byspace-selfhosted) | Packages the BySpace web UI and a local daemon as a Docker deployment.                                 |
| [Devbox Fleet](https://github.com/omrihaviv/devbox-fleet)              | Provisions and maintains per-developer GCP devboxes with BySpace, coding agents, and Tailscale access. |
