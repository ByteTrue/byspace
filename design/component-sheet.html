shadcn 文档页的排版

浅色

What changed

Both stores now hydrate from the same daemon snapshot, so switching hosts no longer drops the open tabs.

  • Composer.tsx holds the input, attachments and send.
  • An empty input keeps a disabled send button.
I left the Expo screens untouched until the web shell can stand on its own.
packages/web/src/composer/send.ts 
export function canSend(draft: Draft) {
  // keep the button visible; disable it instead
  return draft.text.trim() !== "" || draft.files.length > 0
}
